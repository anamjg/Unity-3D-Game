# Unity-3D-Game
Interaction system for a 3D first-person game in Unity

This system is not completed. 

So far the system works for picking up items, throwing them, dropping them, and using them. 

The consumable items will be deleted after being "used". 
Other items cannot be used by themselfs, and lastly the hammer will be able to fix a other objects if planks and nails are close by.
